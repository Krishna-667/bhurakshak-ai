BhuRakshak Final Demo - SMS Notification Edition
=================================================

1) Backend (local)
   cd backend
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   uvicorn main:app --reload --port 8000

2) Frontend (another terminal, from project root)
   npm install
   npm run dev
   Open http://localhost:5173

Demo login
   Admin: admin@bhurakshak.demo / Admin@123
   User : user@bhurakshak.demo  / User@123

SMS demo
   Admin -> SMS Notifications -> choose an alert -> Send SMS.
   The button simulates a successful SMS delivery and records it in the FastAPI
   notification log. It does NOT send a paid SMS and needs no Twilio/MSG91 key.

Vercel + Render deployment
   Backend: deploy the backend folder to Render using render.yaml.
   Set FRONTEND_URL to the final Vercel URL on Render.
   Frontend: deploy the repository to Vercel. Set VITE_API_BASE_URL to the
   public Render backend URL, e.g. https://your-bhurakshak-api.onrender.com
   Then redeploy the Vercel project.

Important
   This version is a demonstration/simulation system. Sensor readings are
   generated by FastAPI and are not operational mine-safety predictions.

SMS DEMO: Admin -> SMS Notifications -> select any node -> Send SMS Alert Bundle. Three node-specific safety messages are stored as SENT/DELIVERED. The Community User portal polls the same backend and shows a notification badge, notification center, and message list automatically.
